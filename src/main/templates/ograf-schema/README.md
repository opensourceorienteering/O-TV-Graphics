# OGraf v1 JSON schemas (EBU)

Copied unchanged from https://github.com/ebu/ograf (`v1/specification/json-schemas/`, MIT licence, see LICENSE) so
manifests are checked against the official schema without a network connection. Their `$id`s are the
`https://ograf.ebu.io/v1/specification/json-schemas/...` addresses the files reference.

To update: copy the same files from the repository again and run `npx vitest run src/main/templates`.
