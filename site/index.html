What it does

Live timing data

Liveresultat (instant push updates), MeOS directly through its information server, MOP databases and IOF XML 3.0 files from any timing software.

Graphics for the whole race

Live split at radio controls, runner focus with a running clock, start lists, results with position changes, split comparison, podium, weather, timer and more.

Ten looks, and your own

Standard comes with the app. Download Svensk Orientering, IOF, IOF 2.0, Contours, ČO, Classic, Bold, Brutal or Signal, or share your own look as a zip file.

Web and NDI output

A transparent browser source for OBS, vMix and CasparCG, and NDI 6 with transparency.

Fast operation

One key per action, a command palette (1 3 F = live split, class 3, finish), favourites, and Stream Deck through Bitfocus Companion.

Director start alerts

A page on any phone or tablet on the network with the next starters and sounds before favourite runners start.

Get started in five steps

1. Install

Download and open the app for your computer.

2. Add timing data

Settings → Data sources: Liveresultat, MeOS, a MOP database or an IOF XML file.

3. Plan the event

Create an event and follow the Plan checklist: data, output, theme, templates, start lists.

4. Add the output

Add http://<computer>:5657/output as a browser source, or pick the NDI source.

5. Go live

Choose a graphic, check it in Preview, press Space to show it.

The manual covers every step in detail.

Build your own look

Graphics are plain web files. Change a look's colours and fonts, or build a new one, and test it in the browser with a simulated race. Developer guide · Preview tool
