Frequently asked questions

Can't find your answer? Read the manual or ask on GitHub.

General

What does Split Control cost?

Nothing. Split Control is free and open source.

Was this called OL-Grafik before?

Yes. Split Control is the new name of OL-Grafik. Your events are kept: the app still stores its data in the OL-Grafik folder.

Which computers does it run on?

Windows 10 and 11 (64-bit) and Macs with Apple Silicon (M1 and newer). It also runs on Linux when built from the source code.

Intel Macs are not built yet.

Which production software does it work with?

Anything that takes a browser source or NDI: OBS, vMix, CasparCG, Wirecast, TriCaster and others. See Set up the outputs.

Does it need the internet during the broadcast?

Only if your timing data comes from the internet (Liveresultat) or you use automatic weather. With MeOS or an IOF XML file on the local network, it works fully offline.

Club logos come with the app, so nothing is fetched from Eventor during a broadcast.

Installing

Windows says "Windows protected your PC"

The app is not signed yet, so SmartScreen doesn't recognise it. Choose More info → Run anyway.

macOS won't open the app, or says it is "damaged"

The app is not signed yet. Right-click Split Control in Applications, choose Open, then Open again.

If macOS says the app is damaged, open Terminal and run:

xattr -dr com.apple.quarantine "/Applications/Split Control.app"

Then open it again.

Do I need to install NDI separately?

No, NDI support is built in. If Split Control says the NDI Runtime is not installed, install NDI Tools and restart Split Control.

The web output works without NDI.

Where are my events stored? How do I back them up?

%APPDATA%\OL-Grafik on Windows and ~/Library/Application Support/OL-Grafik on macOS. Copy the DATAROOT folder to back up every event.

To move one event's setup, use Export settings… in Plan → Final check.

Timing data

Which timing systems are supported?
  • Liveresultat, with instant push updates.
  • MeOS, directly through its information server.
  • MOP databases (MySQL/MariaDB).
  • IOF XML 3.0 files from any timing software: OE/OS, OLA, MeOS, Helga and others.
How fast do results appear on screen?

With Liveresultat and Instant updates (push) on, as soon as Liveresultat has them. Without push, it is polled every 10 seconds.

MeOS and databases can be read every second, so radio controls appear almost at once.

The race has no bibs. Can I still pick runners by number?

Yes. In Plan → Start lists, choose Assign virtual bibs. Runners get numbers like V105, and in the command palette 105 finds V105. Virtual bibs never go to the timing system.

A radio control or club name looks wrong on air

Rename radio controls in Plan → Radio controls, for the whole competition or one class.

Shorten club names in Plan → Start lists → Club names on air. These names are used in every event.

"Test connection" fails
  • Liveresultat: check the internet connection and that the right competition is selected.
  • MeOS: check that Services → Information server is running in MeOS and that the address and port (2009 by default) are right. If MeOS is on another computer, use its IP address and allow the port through its firewall.
  • IOF XML: check that the file exists and that the timing software still exports it.

On air

The browser source is empty
  • Check that Split Control is running and the event is in Live.
  • Open http://<computer>:5657/output in a normal browser on the production computer. If it doesn't load, check the address and the firewall.
  • Set the browser source to the same size as Split Control's resolution (1920 × 1080 by default).
  • Use Put test pattern on air in Plan → Output to check the path.
Red and blue look swapped on NDI

Change the colour format to RGBA in Settings → Output defaults.

Why did a graphic disappear when I showed another one?

Graphics in the same part of the screen clash. Showing a results table removes a lower third, for example; the clock stays. You can turn this off in Plan → Theme (Take clashing graphics off air automatically).

The results table doesn't update

Results tables and the podium hold their data while on air so they don't jump. Press U to update. You can change this per graphic in Plan → Templates.

The keys don't do anything

Single keys are off while you type in a field. Press Esc to leave the field first. Ctrl/Cmd + K works everywhere.

Can I use a Stream Deck?

Yes, through Bitfocus Companion. Split Control comes with a Companion module that turns favourites into buttons. See Stream Deck and remote control.

Can two people run the desk at once?

One computer runs the desk. Others can help from the network: the director page shows upcoming starters, and Companion or the HTTP control API can show favourites and hide graphics.

Is it safe on a public network?

No. The director page and control APIs have no password, so anyone on the network can use them. Run Split Control on your own production network.

Graphics

Can I use my own colours and logos?

Yes. In Plan → Theme, choose a look, pick three colours that every graphic follows, add the event logo, and add or replace club logos as <Club name>.png in the logo folder.

Where are the Svensk Orientering, IOF, ČO and other looks?

Only Standard comes with the app. Download the others from the Looks page, then choose Graphics library → Import look… in Split Control.

Plan says "This look is not installed"

The event uses a look that isn't on this computer, for example an event made before looks were downloads, or copied from another computer. Import the look from the Looks page, or choose another look in Plan → Theme.

How do I move a look to another computer?

In Graphics library, choose Export… next to the look. On the other computer, choose Import look… and pick the zip.

Can I make my own graphics?

Yes. Split Control uses standard EBU OGraf graphics. Zip the graphic's folder and choose Graphics library → Import look….

To build a whole new look, see Template sets.

Does it support GPS tracking?

Not yet. Tracking providers such as Livelox and Loggator each have their own API and there is no shared standard.

How can I practise before race day?

Replay a finished Liveresultat race as if it were live. See Replay a race.
