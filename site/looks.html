Looks

A look is the style of every graphic in an event: colours, fonts, layout and motion. Every look has the same graphics, so you can change the look of an event at any time. Standard comes with the app; download any other look here and import it.

To install a look: download its zip, then in Split Control open Graphics library → Import look… and choose the zip. Don't unzip it.

Then pick the look for an event in Plan → Theme. Try any look first in the preview, with a simulated race. More about looks
